## Resolution Method & Caveats

### How FKs Were Detected

1. **`TableNameOID` pattern** (primary method): A column like `AFDELINGOID` is resolved to the table `AFDELING` whose primary key is `AFDELINGOID`.
2. **Exact PK column match** (fallback): A column like `AFTALEHISTORIKOID` is resolved to the table whose single-column PK is `AFTALEHISTORIKOID` (e.g., `BP30615_AFTALEHISTORIK_BACKUP`).
3. **Self-referencing**: Columns like `STEDOID` in table `STED` are flagged as self-referencing FKs.
