# Adopters

This file lists the organizations that use Healthpipe. The list starts empty.

## Add your organization

1. Fork the repository.
2. Add one row to the table below. Put the rows in alphabetical order of the organization name.
3. Commit the change with a DCO sign-off (`git commit -s`).
4. Open a pull request against `main`.

The maintainers carry the row into the next release, as [CONTRIBUTING.md](CONTRIBUTING.md#how-a-release-replaces-the-tree) describes.

Only add your organization if you have permission to name it in public.
